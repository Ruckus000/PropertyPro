PM “Website” editor — existing-design reference

Where a property manager builds and publishes their community’s public site (shown at [slug].getpropertypro.com, the Florida §718.111(12)(g) statutory site). This file reproduces today’s look faithfully so a redesign starts from an accurate baseline. Full behaviour, copy, states, and data wiring are in website-editor-spec.md.

Section 1 is the page inside the full app shell (a realistic Professional-plan community, mid-edit). Section 2 breaks out the conditional states that can’t all co-exist in one screenshot — Pro-locked vs unlocked, the five custom-domain variants, header/publish-badge variants, and empty states. Everything in a dashed coral box is an annotation, not part of the UI.
