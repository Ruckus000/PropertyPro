Packages are a daily front-desk workflow in apartment and condo communities. PropertyPro logs what came in, who it's for, and when it was picked up — so lost packages become rare and disputes have evidence.

<FeatureGate feature="apartment and condo communities">
Package logging is available in apartment and condo communities with concierge or package-hold services. HOAs usually don't run this workflow centrally.
</FeatureGate>

## What staff log

For each package:

- **Unit** — which unit the package is for
- **Recipient** — resident name
- **Carrier** — USPS, UPS, FedEx, Amazon, etc.
- **Tracking number** (optional)
- **Notes** — optional staff notes

## Accepting a package

<StepByStep>
<Step title="Open Packages → Log Package">
From the Packages page, click **Log Package**.
</Step>

<Step title="Enter unit and recipient">
Fill in the unit number and recipient name.
</Step>

<Step title="Record carrier and tracking">
Select the carrier and add an optional tracking number and notes.
</Step>

<Step title="Submit">
The package is logged and the resident is notified.
</Step>
</StepByStep>

## Releasing a package

When the resident arrives:

<StepByStep>
<Step title="Find the package">
Use the **Pending** filter tab to see packages awaiting pickup.
</Step>

<Step title="Mark Picked Up">
Click **Mark Picked Up** on the package row.
</Step>

<Step title="Enter Picked Up By">
In the dialog, enter the name of the person picking up the package.
</Step>

<Step title="Confirm Pickup">
Click **Confirm Pickup**. The package moves to the Picked Up list.
</Step>
</StepByStep>

## What residents see

Residents see a flat **My Packages** list with status badges for their own packages. There are no separate Open, Recent, or History sections, and no sender or time filters.

## Common scenarios

- **Package for a former resident** — refuse or return. Never release to someone other than the current resident of record.
- **Packages held too long** — use the **Pending** tab to find unclaimed packages. Follow up via notification, then phone if needed.
- **Mis-addressed packages** — if a package arrives for a unit that doesn't exist, note it and return to the carrier.
- **Refused packages** — if a resident refuses their package (incorrect order, returned purchase), note it and return to the carrier.

## Liability

<Callout type="tip" title="Be clear about limits">
The package log is a service, not insurance. Post your community's package-handling policy — typically something like "The association makes reasonable efforts to accept and secure packages but cannot be held liable for loss." Train staff on that language so they don't accidentally accept broader liability.
</Callout>

## When automated lockers are in use

If your community has a locker system (Luxer, Package Concierge):

- Lockers log independently; PropertyPro can mirror or augment the locker data
- Oversized packages typically still come to the front desk
- Keep the concierge as a backup for carrier overflow
