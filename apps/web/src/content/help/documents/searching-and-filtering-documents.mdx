The document library holds every record your association has posted. These tools help you narrow the list to what you're looking for.

## Three ways to narrow the list

<StepByStep>
<Step title="Category filter">
The sidebar groups documents by statutory category — Governing Documents, Annual Budget, Meeting Minutes, Contracts, Insurance, and more. Click any category to show only that type.
</Step>

<Step title="Library search">
The search bar at the top of the library searches filenames, descriptions, and uploader names. Partial matches work — searching "bud" finds "Annual Budget 2026."
</Step>

<Step title="Top-bar search">
For a fuzzier search across documents, meetings, residents, and announcements at once, use the main search at the top of every page. It's the fastest way to find "the thing about landscaping" without knowing which section it's in.
</Step>
</StepByStep>

## Filter by date

If you know roughly when a document was posted, use the date range filter on the library page. Pick a start and end date to narrow the list — useful for finding "the minutes from March" or "this year's financials."

## Filter by posting status

Each document shows whether it was posted on time, late, or is still missing. Admins can filter by status to triage late or missing records from the compliance dashboard.

<Callout type="tip" title="Residents can ignore the status indicator">
The posting status exists for compliance tracking. As a resident, every file you can see is available to you regardless of status — the icon just reflects when it was uploaded relative to the statutory window.
</Callout>

## Searching inside documents

The library search matches filenames and descriptions but doesn't search the text inside PDFs. If you need to find a phrase inside a long document, open the document and use your browser's Find feature (Ctrl/Cmd+F).

## If you can't find something

- **Category mismatch** — try switching to "All categories" and searching the full text.
- **Access restriction** — some documents are admin-only or owners-only. If you expect to see a file that isn't there, contact your manager to verify your role.
- **Not yet posted** — minutes and budgets often lag their approval by days or weeks. If a record is missing after more than a month, raise it with the board.
