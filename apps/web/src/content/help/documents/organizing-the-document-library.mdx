A well-organized library makes your community transparent, accelerates compliance, and reduces the "where's the budget?" emails. A few hours of curation pays back for years.

## Category hygiene

Each community has a fixed set of document categories. A condo or HOA has Governing Documents, Financial Records, Meeting Records, Correspondence, Contracts, Inspection Reports, Insurance, and Elections; an apartment community has Lease Agreements, Maintenance Records, Communications, Financials, Compliance, Rules, Community Handbook, and Move In/Out Docs. Categories keep the library organized and control who can see each file — compliance is tracked separately, by linking documents to requirements on the Compliance dashboard. Put every file in the category that fits best.

<Callout type="warning" title="Category is required for new uploads">
Every new upload requires a category. Older files in the library may still be uncategorized — audit those quarterly and move anything that belongs in a real category.
</Callout>

## Versioning

When a document is updated — annual budget, insurance cert, bylaws amendment — delete the old file and re-upload with a consistent title. For documents created through **Author Document**, use the authored-document versioning flow instead.

If a document is materially changing (not a minor correction), consider:

1. Deleting the old version after confirming retention rules.
2. Uploading the new version.
3. Posting a short announcement explaining the change.

## Retention

Florida statute and your bylaws govern how long records must be kept. Common patterns:

- **Permanent**: governing documents, meeting minutes, election records.
- **Seven years**: most financial records (per statute).
- **At least current year + prior**: budgets, financial reports, audits.

PropertyPro doesn't auto-delete — retention is a policy you apply manually. Don't remove old records without verifying retention rules first.

## Access restrictions

Who can see a document is controlled by its category — PropertyPro applies category-based access policies per role. Pick the category that matches the intended audience when you upload.

## Quarterly audit

Every quarter, scan the library with these questions:

1. **Are all compliance requirements satisfied?** Open Compliance, filter to Unsatisfied, and link a document to each gap.
2. **Are there uncategorized files?** Reclassify any that belong in a real category.
3. **Are duplicates present?** Keep the latest version and delete older ones per retention policy.
4. **Are descriptions useful?** The description powers search — "Meeting Minutes 2026-03-15" is better than "minutes.pdf".

<Callout type="tip" title="Split big PDFs">
A 200-page year-end package is hard for residents to search. Split it into logical sections — budget, auditor letter, meeting minutes — and upload each separately under the right category.
</Callout>

## Cross-linking

When a document references another — a contract modifying a bylaw, an audit referencing budgets — mention the related doc in the description. PropertyPro doesn't link automatically, but a short reference ("See Annual Budget 2026") makes the library easier to navigate.

## Renaming files

PropertyPro displays the **Title** in the library list with the original filename shown beneath. Enter a clear title when you upload — the filename can stay as-is on your desktop.
