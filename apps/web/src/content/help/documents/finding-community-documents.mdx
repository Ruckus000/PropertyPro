## Browse by category

The Documents page organizes files into categories such as governing documents, budgets, minutes, notices, and community rules. Start there if you are exploring rather than looking for a specific title.

## Use search when you know the topic

If you already know what you need, use search to find files by title or keyword. This is the fastest way to jump to a budget, meeting packet, or policy update.

## Admin note

If you are an admin, the same page is where you manage uploads and keep records current for residents.
