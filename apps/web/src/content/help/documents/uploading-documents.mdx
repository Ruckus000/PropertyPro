Uploading documents in PropertyPro isn't just a file transfer — the category keeps the library organized and controls who can see the file, and the finalization date drives the statutory 30-day posting clock.

## Before you upload

Have these ready:

- The file itself (PDF is preferred; Word and images are also accepted)
- The date the record was **finalized** (signed, approved, or adopted) — not the date you are uploading
- A one-line description for residents searching the library

<Callout type="warning" title="The clock starts at finalization">
Florida's 30-day posting window is measured from the date the record was finalized. Setting the correct date matters — an incorrect date can mark an on-time posting as late in the compliance history.
</Callout>

## Upload flow

<StepByStep>
<Step title="Open Documents">
Click Documents in the sidebar, then **Upload** in the top right of the library.
</Step>

<Step title="Choose the file">
Drag and drop or select up to 5 files per upload. Each file is processed independently — if one fails, the others still succeed.
</Step>

<Step title="Pick the correct category">
Pick from the categories set up for your community. A condo or HOA has Governing Documents, Financial Records, Meeting Records, Correspondence, Contracts, Inspection Reports, Insurance, and Elections; an apartment community has Lease Agreements, Maintenance Records, Communications, Financials, Compliance, Rules, Community Handbook, and Move In/Out Docs. The category organizes the library and controls who can see the file — it does **not** by itself satisfy a compliance requirement (you link a document to a requirement separately; see below). If nothing fits, you can leave it uncategorized.
</Step>

<Step title="Set the finalization date">
Enter the date the record was signed or adopted. If you leave it blank, PropertyPro uses today's date.
</Step>

<Step title="Add a short description">
One sentence describing what's inside — residents see this in the library list. This also powers search.
</Step>

<Step title="Set access">
Most documents are visible to all community members. Choose **Admins only** or **Owners only** if a document should be restricted.
</Step>

<Step title="Save">
Click Upload to publish. The document is immediately available and the compliance dashboard refreshes within a few seconds.
</Step>
</StepByStep>

## Replacing an existing document

Always replace in place rather than uploading a new file with a slightly different name. Replacing preserves the audit history and keeps the compliance linkage intact:

1. Open the document in the library.
2. Click **Replace file**.
3. Upload the new version and optionally update the finalization date.
4. Click Save.

Residents see the new version immediately; the old version is archived in the document's history panel.

## Categorization cheat sheet (condo / HOA)

- **Approved meeting minutes, agendas, notices** → Meeting Records
- **Annual budget, financial report, reserve study, audit** → Financial Records
- **Vendor or management contract** → Contracts
- **Certificate of insurance / coverage** → Insurance
- **Candidate materials, ballots, election results** → Elections
- **Declaration / Articles / Bylaws / Rules** → Governing Documents
- **SIRS or milestone inspection summary** → Inspection Reports
- **Owner letters and official notices** → Correspondence

<Callout type="tip" title="When in doubt">
If nothing fits, leave the document uncategorized and add a clear description. Note that uncategorized documents are visible only to owners, board members, and PM admins — not tenants, CAMs, or site managers — so pick a category when residents need to see the file.
</Callout>

## Linking a document to a compliance requirement

Uploading a file to the library does **not** by itself satisfy a compliance requirement — you link it explicitly. Open **Compliance**, find the requirement, and use **Link document** to attach a file already in the library (or **Upload** to add one and attach it in a single step). The requirement flips to Satisfied once a document is linked.

If a requirement is still Unsatisfied after linking:

- Check the finalization date — a future or missing date can place the document outside the posting window.
- Check the file — a zero-byte or corrupt file may not have uploaded cleanly.
- Confirm you linked the document to the requirement, not just uploaded it to the library.
