Uploading documents in PropertyPro isn't just a file transfer — the category keeps the library organized and controls who can see the file.

## Before you upload

Have these ready:

- The file itself (PDF is preferred; Word and images are also accepted)
- A title for the document
- An optional one-line description for residents searching the library

## Upload flow

<StepByStep>
<Step title="Open Documents">
Click Documents in the sidebar, then **Upload Document** in the top right of the library.
</Step>

<Step title="Pick the correct category">
Choose a category — a category is required before you can upload. A condo or HOA has Governing Documents, Financial Records, Meeting Records, Correspondence, Contracts, Inspection Reports, Insurance, and Elections; an apartment community has Lease Agreements, Maintenance Records, Communications, Financials, Compliance, Rules, Community Handbook, and Move In/Out Docs. The category organizes the library and controls who can see the file — residents will only see documents that match their allowed category access. It does **not** by itself satisfy a compliance requirement (you link a document to a requirement separately; see below).
</Step>

<Step title="Choose the file">
Drag and drop or select a file to upload.
</Step>

<Step title="Enter a title">
Enter a **Title** for the document. This is what residents see in the library list.
</Step>

<Step title="Add a short description">
Optionally add a one-line description — this also powers search.
</Step>

<Step title="Save">
Click **Upload Document** to publish. The document is immediately available.
</Step>
</StepByStep>

## Updating an existing document

To update an uploaded file, delete the old document and upload a new one with a consistent title. **Version History** applies to authored documents (created through **Author Document**), not to files uploaded through this flow.

## Categorization cheat sheet (condo / HOA)

- **Approved meeting minutes, agendas, notices** → Meeting Records
- **Annual budget, financial report, reserve study, audit** → Financial Records
- **Vendor or management contract** → Contracts
- **Certificate of insurance / coverage** → Insurance
- **Candidate materials, ballots, election results** → Elections
- **Declaration / Articles / Bylaws / Rules** → Governing Documents
- **SIRS or milestone inspection summary** → Inspection Reports
- **Owner letters and official notices** → Correspondence

<Callout type="tip" title="When in doubt">
Pick the closest category. A category is required for every new upload.
</Callout>

## Linking a document to a compliance requirement

Uploading a file to the library does **not** by itself satisfy a compliance requirement — you link it explicitly. Open **Compliance**, find the requirement, and use **Link document** to attach a file already in the library (or **Upload** to add one and attach it in a single step). The requirement flips to Satisfied once a document is linked.

If a requirement is still Unsatisfied after linking:

- Check the file — a zero-byte or corrupt file may not have uploaded cleanly.
- Confirm you linked the document to the requirement, not just uploaded it to the library.
