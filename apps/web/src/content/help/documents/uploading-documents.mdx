Uploading documents in PropertyPro isn't just a file transfer — the category and the finalization date are what connect the record to your community's statutory obligations.

## Before you upload

Have these ready:

- The file itself (PDF is preferred; Word and images are also accepted)
- The date the record was **finalized** (signed, approved, or adopted) — not the date you are uploading
- A one-line description for residents searching the library

<Callout type="warning" title="The clock starts at finalization">
Florida's 30-day posting window is measured from the date the record was finalized. Setting the correct date matters — an incorrect date can mark an on-time posting as late in the compliance history.
</Callout>

## Upload flow

<StepByStep>
<Step title="Open Documents">
Click Documents in the sidebar, then **Upload** in the top right of the library.
</Step>

<Step title="Choose the file">
Drag and drop or select up to 5 files per upload. Each file is processed independently — if one fails, the others still succeed.
</Step>

<Step title="Pick the correct category">
Use the category dropdown: Governing Documents, Annual Budget, Financial Report, Meeting Minutes, and so on. The category is what links the upload to the correct compliance requirement.
</Step>

<Step title="Set the finalization date">
Enter the date the record was signed or adopted. If you leave it blank, PropertyPro uses today's date.
</Step>

<Step title="Add a short description">
One sentence describing what's inside — residents see this in the library list. This also powers search.
</Step>

<Step title="Set access">
Most documents are visible to all community members. Choose **Admins only** or **Owners only** if a document should be restricted.
</Step>

<Step title="Save">
Click Upload to publish. The document is immediately available and the compliance dashboard refreshes within a few seconds.
</Step>
</StepByStep>

## Replacing an existing document

Always replace in place rather than uploading a new file with a slightly different name. Replacing preserves the audit history and keeps the compliance linkage intact:

1. Open the document in the library.
2. Click **Replace file**.
3. Upload the new version and optionally update the finalization date.
4. Click Save.

Residents see the new version immediately; the old version is archived in the document's history panel.

## Categorization cheat sheet

- **Approved meeting minutes** → Meeting Minutes
- **Annual budget** → Annual Budget
- **Reserve study** → Financial Report
- **Management contract** → Contracts
- **Declaration / Articles / Bylaws** → Governing Documents
- **Rules and regulations** → Governing Documents
- **Insurance certificate** → Insurance
- **SIRS inspection summary** → Financial Report

<Callout type="tip" title="When in doubt">
If nothing obvious fits, upload as "Other" and add a clear description. Your compliance dashboard will flag whatever requirement remains unsatisfied so you can reclassify later.
</Callout>

## After uploading

Visit Compliance to confirm the requirement flipped to Satisfied. If it didn't:

- Check the category — the most common cause is a mismatch.
- Check the finalization date — a future date or missing date can hide the upload from the calculator.
- Check the file — a zero-byte or corrupt file won't satisfy the requirement.
