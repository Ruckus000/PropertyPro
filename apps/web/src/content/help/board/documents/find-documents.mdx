<StepByStep>

<Step title="Open Documents and pick a category" shot="doc-cats">

The newest documents are at the top. Select a category, such as **Governing Documents** or **Meeting Records**, to narrow the list. Select **All** to see everything.

</Step>

<Step title="Search" shot="doc-search">

Select **Search** at the top of the page, type a word and select **Search** again. Titles and descriptions match part of a word, so “bud” finds “Annual Budget”. Text inside a file matches whole words, and only for files marked **Searchable**. The results list each match’s title; find it in the list below to open it.

</Step>

<Step title="Open a document" shot="doc-row">

Select the document’s title. Its preview opens beside the list. PDFs and images preview; other files show **Preview not available for this file type**.

</Step>

<Step title="Or download it" shot="doc-dl">

Select **Download** above the preview. Word files cannot preview in the browser, so download them to read them.

</Step>

</StepByStep>

## Records not posted yet

As an owner you also see the records the association is required to post. A row marked **No file on record** is one that has not been added yet, and the **State** column shows whether each file is **On the public site** or **Owners only**. Uploading, linking and publishing records is done by your manager.

</OnlyFor>

<OnlyFor types="apartment">

## Apartment communities

</OnlyFor>

<OnlyFor types="apartment">

Apartment libraries use different categories: Lease Agreements, Rules, Community Handbook, Move In/Out Docs and others.

</OnlyFor>

## If you cannot find a document

- Switch to **All** and search again. It may be in another category.
- Some categories are limited by role, so a category can look empty to you. If you expect to see something, ask your manager to check.
- Minutes and budgets are often posted days or weeks after approval.

<OnlyFor types="condo_718 hoa_720">

<Callout type="florida-statute" title="Your right to see records">

Florida Statute §718.111(12)(g) (condos with 25+ units) and §720.303(4) (HOAs with 100+ parcels) require official records to be posted on the association website or portal.

</Callout>

</OnlyFor>
