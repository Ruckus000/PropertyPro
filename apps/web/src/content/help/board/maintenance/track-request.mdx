Open **Operations**, then **Requests**. Each of your requests shows its title, description and status.

<Figure shot="mr-list" alt="Requests tab listing a request with its status" />

- A new request shows **Submitted**.
- If its status changes, for example to **In Progress** or **Closed**, you get an email and a notification.

<Callout type="tip" title="If the problem comes back">

Requests cannot be reopened or commented on. Submit a new request that says what is still wrong. If a non-urgent request has not moved in a few days, contact your manager.

</Callout>
