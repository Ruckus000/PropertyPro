**Units** is in the sidebar under **Admin**.

<Figure shot="un-list" alt="Units list with unit, building and floor">

<OnlyFor types="apartment">Apartment communities also see each unit’s rent.</OnlyFor>

</Figure>

<StepByStep>

<Step title="Select Add unit" shot="un-add">

Enter the **Unit number** exactly as it appears in association records, and the **Building** and **Floor** if you use them, then select **Add unit**. People type this number when they ask to join, so leading zeros and letters matter.

</Step>

</StepByStep>

Units cannot be edited or deleted on this page, so check the number before you add it.

Assessments are charged per unit, so check the list before [creating an assessment](help:create-assessment).
