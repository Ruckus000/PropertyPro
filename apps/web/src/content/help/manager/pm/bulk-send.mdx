<StepByStep>

<Step title="Select the communities" shot="bk-select">

On **Communities**, select **List view**, then check the rows. **Bulk announcement** and **Bulk documents** appear at the top with the count.

</Step>

<Step title="Write it once" shot="bk-dialog">

Enter a **Title** and **Body**, choose the **Audience**, and check **Pin this announcement** if needed. Every community gets exactly the same text.

</Step>

<Step title="Select Review & Send, then Confirm & Send">

It publishes in each selected community.

</Step>

</StepByStep>

**Bulk documents** works the same way: choose the **Files**, add an optional description, then **Review & Upload** and **Confirm & Upload**. Bulk uploads have no category; set it in each community afterward.

<Callout type="warning" title="There is no undo">

To retract, delete it in each community and send a correction. Proofread first.

</Callout>
