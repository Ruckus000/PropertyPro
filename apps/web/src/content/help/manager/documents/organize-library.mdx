Every new upload needs a category. Older files may not have one: they show **—** in the **Category** column, appear only under **All**, and tenants cannot see them.

<OnlyFor types="condo_718 hoa_720">

<Figure shot="org-unlinked" alt="Documents list filtered to Unlinked files">

**Unlinked** lists files that no compliance requirement points at.

</Figure>

</OnlyFor>

## Each quarter

<OnlyFor types="condo_718 hoa_720">

- Open **Compliance** and select **Action needed**. Upload or link a record for each row.
- In **Documents**, select **Unlinked** and check whether any of those files should satisfy a requirement.

</OnlyFor>

- Find files with no category under **All**. There is no way to change a file’s category, so upload it again into the right category and delete the old copy.
- Delete duplicates, keeping the newest, after checking retention. A deleted file stays in the **Board** view under **Deleted**, where you can **Restore** it.
- Descriptions cannot be edited after upload, and search uses them. If one is vague, upload the file again with a better description.
- Split large packets (a 200-page year-end package) into separate uploads by category.

<OnlyFor types="condo_718 hoa_720">

<Callout type="warning" title="Retention is manual">

PropertyPro never deletes records by itself. Governing documents, minutes and election records are generally kept permanently, and most financial records for 7 years. Check your statute and bylaws before deleting anything.

</Callout>

</OnlyFor>
