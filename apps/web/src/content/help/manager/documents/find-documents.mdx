<StepByStep>

<Step title="Open Documents and pick a category" shot="doc-cats">

The newest documents are at the top. Select a category, such as **Governing Documents** or **Meeting Records**, to narrow the list. Select **All** to see everything.

</Step>

<Step title="Search" shot="doc-search">

Select **Search** at the top of the page, type a word and select **Search** again. Titles and descriptions match part of a word, so “bud” finds “Annual Budget”. Text inside a file matches whole words, and only for files marked **Searchable**. The results list each match’s title; find it in the list below to open it.

</Step>

<Step title="Open a document" shot="doc-row">

Select the document’s title. Its preview opens beside the list. PDFs and images preview; other files show **Preview not available for this file type**.

</Step>

<Step title="Or download it" shot="doc-dl">

Select **Download** above the preview. Word files cannot preview in the browser, so download them to read them.

</Step>

</StepByStep>

## Statutory records in the list

Required records with no file appear at the top as **No file on record**. Select **Owed to public** to see files that should be on the public site and are not, and **Unlinked** to see files no compliance requirement points at.

</OnlyFor>

## If you cannot find a document

- Switch to **All** and search again. It may be in another category.
- Check the document’s category. Categories control who can see each file.
- A deleted document is in the **Board** view, in the **Deleted** column. Select it, then select **Restore**.
