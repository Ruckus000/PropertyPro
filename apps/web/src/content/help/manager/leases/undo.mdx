<StepByStep>

<Step title="Select Undo" shot="un-1">

Most changes show a confirmation at the bottom of the screen with **Undo**. It stays for about 7 seconds.

</Step>

</StepByStep>

## After the confirmation closes

- **Early end:** open the unit and select **Cancel early end**. This works until the last day.
- **Transfer:** select **Cancel transfer** on either unit before the move-in date.
- **Move-out or declined offer:** select **Cancel move-out**. If the unit is pre-leased, cancel the upcoming lease first.
- **Signed renewal:** select **Cancel renewal** on the Renewal term card.
- **Upcoming lease:** select **Cancel upcoming lease**. See [Edit or cancel an upcoming lease](help:upcoming-lease).
- **Accepted offer:** select **Undo acceptance**.
- **Lease details:** select **Edit lease** and change them back.
- **Offline unit:** select **Bring back online**.
- **Alert windows:** choose the previous option in **Expiry alerts**.

You cannot remove a lease that has already started from this page.
