<StepByStep>

<Step title="Select Record renewal" shot="rec-1">

The row shows this link after an offer is accepted. For any other lease, open the unit and select **Record signed renewal**.

</Step>

<Step title="Choose Record a signed renewal" shot="rec-2">

If you started from an accepted offer, this is already selected and the offer’s terms, residents and deposit are filled in.

</Step>

<Step title="Check the start date, rent and deposit" shot="rec-3">

The start date defaults to the day after the current lease ends. If you pick an earlier start, the current lease ends the day before it. If the deposit goes up, the §83.49 notice fields appear.

</Step>

<Step title="Select Record renewal" shot="rec-4">

Attach the signed copy first if you have it. The row then shows **Renewed** and the new start date. The current lease stays in effect until then.

</Step>

<Step title="To change or undo it, use the Renewal term card" shot="rec-5">

Select **Edit** to correct the renewal, or **Cancel renewal** if you recorded it by mistake.

</Step>

</StepByStep>

<Callout type="info" title="Holdovers and month-to-month">

For a holdover, the start date can be in the past, and the renewal is backdated. For a month-to-month lease, open the unit, select **Offer a fixed term**, then choose **Record a signed renewal**.

</Callout>
