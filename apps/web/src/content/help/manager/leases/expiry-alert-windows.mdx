The expiry alert setting decides how early a lease counts as **Expiring** and appears in **Renewals due**. The widest window is the one that counts. With **30, 60, 90 days**, a lease shows up 90 days before it ends.

## Change the setting

<StepByStep>
<Step title="Select Expiry alerts" shot="step-1">
It is in the list header, between **Past leases** and **New lease**, and shows the current setting, for example **Expiry alerts: 30, 60, 90 days**. A menu opens. Its first line says **Leases ending within the widest window count as Renewals due.**
</Step>

<Step title="Choose an option" shot="step-2">
Choose **30, 60, 90 days**, **30, 60 days**, **60, 90, 120 days**, **30 days** or **90 days**. The current setting is marked.
</Step>

<Step title="Check the result" shot="step-3">
A confirmation says **Expiry alerts set to** the new windows, and includes **Undo**. The **Renewals due** tile changes to **Ending within** the new widest window, and units move between **Leased** and **Expiring** to match.
</Step>
</StepByStep>

The setting applies to every manager of this community.

<Callout type="info" title="Only the root manager can change this">
Other managers see the same menu with the options greyed out and the line **Only the root manager can change this.**
</Callout>

## Allow household members on leases

The same menu has a **Lease settings** heading with one checkbox, **Allow household members on leases**. It is off unless the root manager turns it on. Select it to turn it on or off. A confirmation says **Household members with no portal login can now be named on leases** or **Household members can no longer be added to leases**. This confirmation has no **Undo**: select the checkbox again to switch back.

When it is on, the **Residents** field in the **New lease** and renewal offer dialogs lists the unit's household members from the Directory and offers **Add a household member**. Turning it off doesn't remove anyone from a lease they are already on. See [Add a lease or pre-lease a unit](help:adding-a-lease).

## Choosing a window

- A lease's **Notice to leave at term end (days)** can be up to 60 days. For those leases, a widest window of 90 or 120 days leaves time to send a renewal offer before the resident's notice deadline. The unit panel shows each lease's deadline.
- **30, 60 days** or **30 days** suits short terms, where 90 days would put most leases in **Renewals due**.

The windows don't send reminders. They only change which leases count as **Expiring** and **Renewals due**. The colours in the **Lease end** column don't change with this setting: amber within 30 days, a clock within 7 days, and red once the end date has passed.
