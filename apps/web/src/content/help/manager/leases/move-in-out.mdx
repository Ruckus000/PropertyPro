A move-in checklist is created with every new lease, including renewals. A move-out checklist is created when you terminate a lease. Both appear on **Move In/Out**, under **Leases** in the sidebar.

<Figure shot="mio-list" alt="Move In/Out page with checklist cards and progress">

Use the **All**, **Move In** and **Move Out** tabs to filter the cards. Each card shows the unit, the lease number and how many steps are done.

</Figure>

<StepByStep>

<Step title="Open a checklist and check off each step" shot="mio-card">

Select a card, then select a step's name to check it off. Select it again to uncheck it. Select **Notes** under a step to add a note.

</Step>

</StepByStep>

- **Move-in:** Lease signed, Security deposit recorded, Move-in inspection scheduled, Keys/access cards assigned, Parking assigned, Resident portal account created, Welcome packet sent, Utilities transfer confirmed.
- **Move-out:** 30-day notice received, Move-out inspection scheduled, Move-out inspection completed, Security deposit disposition calculated, Keys/access cards returned, Parking assignment cleared, Portal access deactivated, Security deposit refund processed.

## Steps with a button

Some steps can do the work for you and check themselves off:

- **Schedule Inspection** creates an inspection request for the unit.
- **Send Portal Invite** sends the resident an invitation to the portal.
- **Send Welcome Packet** emails the resident a welcome message.

Select **Back to checklists** to return to the list.

<Callout type="florida-statute" title="Florida Statute §83.49">

Normal wear cannot be deducted from a deposit; damage can. Return the deposit within **15 days**, or send a written claim by certified mail within **30 days**.

</Callout>
